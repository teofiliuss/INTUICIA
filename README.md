# Тренажор на интуицията

Едностранично уеб приложение за трениране на интуицията. Има три режима: число от 0 до 100, червено или синьо, и четири цвята. Случайният резултат се тегли едва след „СТАРТ“ чрез `crypto.getRandomValues`.

Последните 100 опита за всеки режим се пазят в браузъра. Показват се успеваемост, поредица от попадения и едностранен биномен тест спрямо случайността. Има звук и експорт в CSV.

Отворете тренажора: https://teofiliuss.github.io/INTUICIA/
